# StatMonitor ⚽📈

Інтелектуальна система спортивного моніторингу коефіцієнтів, аналізу прогрузів ліній за допомогою **Google Gemini AI з Google Search Grounding**, автоматичного віртуального трейдингу (**Paper Bank**), спостережливості (**Web Dashboard**) та доставки аналітики й графіків у **Telegram**.

---

## ⚡ Ключові можливості

1. **Моніторинг 14 топових ліг**: АПЛ, Ла Ліга, Серія А, Бундесліга, Ліга 1, УПЛ, Екстракласа, єврокубки (ЛЧ, ЛЄ, ЛК, Ліга Націй), НБА та підсумкові турніри ATP/WTA.
2. **AI-аналіз матчів (Gemini + Google Search)**: каскад моделей (`3.5-flash-lite` $\rightarrow$ `2.5-flash-lite` $\rightarrow$ `2.5-flash` $\rightarrow$ `3.8-flash`) із живим пошуком свіжих новин, лазарету, стартових складів, форми та чуток у реальному часі.
3. **Paper Bank (10 000 грн)**: автоматичне віртуальне ведення банку, динамічний стейкінг 2–4%, авторозрахунок за фінальними рахунками (`WON`, `LOST`, `VOID`) та щоденний звіт з ROI.
4. **Smart Rate-Limiter & Credit Budgeter (`statmonitor/limiter.py`)**: динамічна класифікація ліг на HOT (< 6 год), WARM (6..24 год) та COLD (> 24 год) з автоматичними режимами економії (NORMAL/ECO/CRITICAL), що зберігає до 80% квоти The Odds API.
5. **Інтерактивний Web Dashboard (Streamlit Cloud)**: повнорозмірний веб-інтерфейс із динамічним графіком капіталу Plotly, картками AI-вердиктів, таблицями ставок і монітором розкладу та безпечним RBAC-доступом (режим перегляду для гостей та адмін-режим із тригером).
6. **Модульна архітектура пакету (`statmonitor/`)**: розподіл обов'язків на чисті модулі (`pipeline`, `fetcher`, `limiter`, `database`, `ai`, `paper_trading`, `chart`, `notifier`, `config`) та лаконічний оркестратор `main.py` зі збереженням 100% зворотної сумісності.
7. **Високоточний гібридний тригер**: виклик воркфлоу секунда в секунду через **Cloudflare Worker** (`statmonitor.symchak.workers.dev`) + **Cron-job.org**, плюс резервний cron у GitHub Actions (`15,45 * * * *`).
8. **Динамічний планувальник (`scheduler.py`)**: автоматичний розрахунок контрольних точок за 15 хв до початку матчів (Closing Line Value), через 115 хв для розрахунку ставок, автофіксація статусу `EXECUTED` та захист від дублікатів.
9. **Watchdog пульсу (`sys_watchdog.py`)**: автоматичний контроль запізнень черг та алерти в Telegram при затримках $> 25$ хв із розумною фільтрацією повторів.
10. **Версіоновані міграції БД (`migrate.py`)**: DDL-схема, журнал `schema_migrations`, B-Tree індекси на `odds_history`, `events`, `paper_bets`, `sports_poll_log` та оптимізована в'юшка `v_odds_alerts`.
11. **Вичерпний набір тестів (33 unit-тести)**: тести лімітера (`test_rate_limiter.py`), парсингу й розрахунку маркетів (`test_eval_picks.py`), цілісності модулів (`test_modules.py`), планувальника, watchdog, міграцій та дашборду.

## 🛠 Технологічний стек

* **Мова**: Python 3.10+
* **База даних**: PostgreSQL 15+ (Supabase) + автоматичний раннер міграцій `migrate.py`
* **API котирувань**: The Odds API v4 (із резервним ключем, сумарний пул 1000 запитів)
* **Штучний інтелект**: Google Gemini API (v1beta) з інструментом Google Search Grounding
* **Веб-інтерфейс**: Streamlit Cloud (`dashboard.py` + Plotly)
* **Візуалізація трендів**: Matplotlib (рендеринг у пам'яті без дисків)
* **Канал сповіщень**: Telegram Bot API (HTML-розмітка, чанкінг $\le 3800$ симв.)
* **Оркестрація**: GitHub Actions + Cloudflare Workers
* **Тестування**: `unittest` (27 тест-кейсів, час виконання < 0.01 с)
