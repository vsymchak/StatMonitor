# StatMonitor ⚽📈

Інтелектуальна система спортивного моніторингу коефіцієнтів, аналізу прогрузів ліній за допомогою **Google Gemini AI з Google Search Grounding**, автоматичного віртуального трейдингу (**Paper Bank**), паралельного обліку реальних грошей (**Real Money Mode & Bet Slip OCR**), спостережливості (**Web Dashboard**) та доставки аналітики й графіків у **Telegram**.

## ⚡ Ключові можливості

1. **Моніторинг футбольних, баскетбольних та тенісних ліг**: АПЛ, Ла Ліга, Серія А, Бундесліга, Ліга 1, УПЛ, Екстракласа, єврокубки (ЛЧ, ЛЄ, ЛК, Ліга Націй), НБА та повне тенісне покриття (ATP, WTA, Davis Cup, Australian Open, Roland Garros, Wimbledon, US Open, Finals) із динамічним автовиявленням активних змагань у The Odds API.
2. **AI-аналіз матчів (Gemini + Google Search)**: каскад моделей (`gemini-2.5-pro` $\rightarrow$ `gemini-2.5-flash` $\rightarrow$ `gemini-3.5-flash-lite` $\rightarrow$ `gemini-3.8-flash`) із живим пошуком свіжих новин, лазарету, стартових складів, форми та інсайдів у реальному часі. Оцінка сили сигналу за шкалою 1–10 (Confidence Score) та валуй-фільтрація ($\ge 7/10$).
3. **Paper Bank (10 000 грн) та стейкінг за критерієм Келлі**: динамічний розрахунок розміру парі за дробовим критерієм Келлі ($0.25 \times \text{Kelly}$, межі 1–5%), авторозрахунок за фінальними рахунками (`WON`, `LOST`, `VOID`) та відображення % банку в активних ставках UI і Telegram.
4. **Реальний банк та Bet Slip OCR (Wave 10, Крок 31)**:
   - **Подвійний банкрол**: паралельний облік реальних грошей через `real_bankroll_ledger`. Реальний банк стартує з 0.00 ₴ і формується виключно реальними депозитами (`DEPOSIT`), виведеннями коштів (`WITHDRAWAL`) та авторозрахунком ставок (`BET_RESULT`).
   - **Інлайн-чекбокс у таблиці активних ставок**: адміністратор може в один клік позначити ставку прапорцем `🟢 Real` безпосередньо в таблиці `st.data_editor` — ставка зараховується в реальний банкрол, паралельно залишаючись у Paper-трейдингу.
   - **AI Bet Slip OCR через Gemini Multimodal Vision**: завантаження фото або скріншота купона ставки з букмекерської контори через адмінку Streamlit, автоматичне розпізнавання матчу, коефіцієнта та суми, і прив'язка купона до бази даних.
   - **Ручний розрахунок (Manual Settle)**: швидке підтвердження результатів ставок адміністратором безпосередньо з веб-панелі.
5. **Інтерактивний Web Dashboard (Streamlit Cloud)**:
   - Повнорозмірний веб-інтерфейс із динамічним графіком капіталу Plotly, аналітикою ризику Max Drawdown, серіями перемог/поразок (Streaks) та сегментацією за лігами й маркетами.
   - Таблиця активних ставок `⏳ Активні ставки в грі (Pending)` із сортуванням за часом початку, іконками видів спорту (⚽, 🏀, 🎾, 🏒, 🥊, 🏈, ⚾), колонками `% банку (Келлі)` та київським часом подій.
   - Банер реального банкролу (Real Balance, депозити, чистий прибуток, ROI %, оборот).
   - 5-ключовий монітор квот The Odds API (основний + 4 резервних, сумарний пул 2500 запитів).
   - Безпечний RBAC-доступ: гостьовий режим (Read-Only) та адмін-режим із керуванням касою, редагуванням коефіцієнтів та ручним розрахунком ставок.
6. **Конфігураційна матриця ліг та динамічні пороги (`config/leagues.json` + `league_thresholds`)**:
   - Декларативне керування списком ліг, назвами, категоріями, ринками та індивідуальними порогами просідання коефіцієнтів.
   - Інтерактивна адмін-панель у Streamlit для зміни порогів (`min_drop_pct`, `min_odds`, `max_odds`, `enabled`) у режимі реального часу зі збереженням у PostgreSQL.
7. **Інтерактивний Telegram-бот (`bot_service.py`)**: двосторонній персональний асистент із клавіатурою швидких дій, командами `/status`, `/bank`, `/bets` (з показом % банку за Келлі), `/today`, `/schedule`, `/digest` та позачерговим запуском моніторингу `/run_now` з перевіркою авторизації `TG_CHAT_ID`.
8. **Smart Rate-Limiter & Credit Budgeter (`statmonitor/limiter.py`)**: динамічна класифікація ліг на HOT (< 6 год), WARM (6..24 год) та COLD (> 24 год) з автоматичними режимами економії (NORMAL/ECO/CRITICAL), що зберігає до 80% квоти The Odds API.
9. **Модульна архітектура пакету (`statmonitor/`)**: розподіл обов'язків на чисті модулі (`pipeline`, `fetcher`, `limiter`, `league_config`, `bot`, `database`, `ai`, `paper_trading`, `real_bankroll`, `slip_ocr`, `chart`, `notifier`, `config`) та лаконічний оркестратор `main.py` зі збереженням 100% зворотної сумісності.
10. **Високоточний гібридний тригер**: виклик воркфлоу секунда в секунду через **Cloudflare Worker** (`statmonitor.symchak.workers.dev`) + **Cron-job.org**, плюс резервний cron у GitHub Actions (`15,45 * * * *`) та програмний шлюз `should_execute_pipeline`.
11. **Динамічний планувальник (`scheduler.py`)**: автоматичний розрахунок контрольних точок за 15 хв до початку матчів (Closing Line Value), через 115 хв для розрахунку ставок, автофіксація статусу `EXECUTED`, захист від дублікатів та фільтрація вікна перегляду (-6 год).
12. **Watchdog пульсу (`sys_watchdog.py`)**: автоматичний контроль запізнень черг та алерти в Telegram при затримках $> 25$ хв із розумною фільтрацією повторів та нічним режимом тиші (00:00 - 08:00).
13. **Версіоновані міграції БД (`migrate.py`)**: DDL-схема, журнал `schema_migrations`, B-Tree індекси на `odds_history`, `events`, `paper_bets`, `sports_poll_log`, `real_bankroll_ledger` та оптимізована в'юшка `v_odds_alerts` (міграції `001`–`014`).
14. **Точні бенчмарк-коефіцієнти та ручне редагування (Wave 7, Кроки 18–19)**: розрахунок медіани провідних букмекерів (Pinnacle/Betfair/Unibet), пакетний перерахунок `recalc_odds.py`, редагування коефіцієнтів у Streamlit Web Dashboard, Telegram-боті (`/edit_odds <ID> <коеф>`) та CLI.
15. **Відстеження Closing Line Value (CLV) та Beat the Line % (Wave 8, Крок 20)**: автоматична фіксація лінії закриття за Pinnacle/Betfair перед початком матчу, розрахунок $CLV\%$ та Beat the Line % для доказу довгострокового $+EV$. Відображення в Web Dashboard (стовпець `CLV (+EV)` і блок у Breakdown) та Telegram-боті (`/bank` та щоденний звіт).
16. **Ринок «Обидві заб'ють» (BTTS) та фільтрація чистих тоталів (Wave 8, Крок 23)**: підтримка ринку BTTS (`Yes` / `No`) у футболі через The Odds API, конфігурацію ліг, автоматичний розрахунок результатів `eval_outcome`, медіанні коефіцієнти та сегментацію в аналітиці. Математичне відсікання азіатських четвертних тоталів (`.25` та `.75`) для виключення шуму в алертах.
17. **Дедуплікація та оптимізація сповіщень Telegram (Wave 8, Кроки 27, 29, 30)**: виключення повторної відправки алертів кожні 2 години для матчів із зафіксованими ставками або проведеним аналізом. Повне відключення спаму технічними повідомленнями та довгими AI-вердиктами у Telegram (збереження в БД). У Telegram надсилаються тільки помилки розкладу, відкриті ставки, зведення та звіти.
18. **Вичерпний набір тестів (162 unit-тести)**: повне покриття модулів No-Vig Edge (`test_novig_edge.py`), реального банку (`test_real_bankroll.py`), OCR купонів (`test_slip_ocr.py`), аналітики ризику та ліг (`test_analytics.py`), матриці ліг (`test_league_config.py`), порогів чутливості (`test_league_thresholds.py`), AI Confidence (`test_confidence.py`), бота (`test_bot.py`), лімітера (`test_rate_limiter.py`), стейкінгу Келлі (`test_kelly.py`), CLV та Beat the Line (`test_clv.py`), ринків BTTS, маркетів та медіани (`test_eval_picks.py`), цілісності модулів (`test_modules.py`), планувальника, watchdog, міграцій та дашборду (`test_dashboard.py`).

## 🛠 Технологічний стек

* **Мова**: Python 3.10+
* **База даних**: PostgreSQL 15+ (Supabase) + автоматичний раннер міграцій `migrate.py` (міграції 001–014)
* **API котирувань**: The Odds API v4 (5-рівнева ротація ключів: основний + 4 резервних, сумарний пул 2500 запитів)
* **Штучний інтелект**: Google Gemini API (v1beta / Multimodal Vision) з інструментом Google Search Grounding
* **Веб-інтерфейс**: Streamlit Cloud (`dashboard.py` + Plotly + `st.data_editor`)
* **Візуалізація трендів**: Matplotlib (рендеринг у пам'яті без дисків)
* **Канал сповіщень**: Telegram Bot API (HTML-розмітка, чанкінг $\le 3800$ симв., анти-спам фільтрація)
* **Оркестрація**: GitHub Actions + Cloudflare Workers
* **Тестування**: `unittest` (149 тест-кейсів, 100% pass, час виконання $\approx 1$ с)
