# StatMonitor ⚽📈

Інтелектуальна система спортивного моніторингу коефіцієнтів, аналізу прогрузів ліній за допомогою **Google Gemini AI**, автоматичного віртуального трейдингу (**Paper Bank**) та доставки аналітики й графіків у **Telegram**.

---

* 🏛 **[Візуальна архітектура системи (docs/architecture.md)](docs/architecture.md)** — детальна C4-схема компонентів, потік даних від тригеру до Telegram, діаграма бази даних (ERD).
* 📊 **[Діаграма дорожньої карти SDD (docs/roadmap-diagram.md)](docs/roadmap-diagram.md)** — візуальний прогрес виконання завдань по хвилях (Wave 1–5).
* 📋 **[Реєстр дорожньої карти (docs/roadmap.md)](docs/roadmap.md)** — повний список 17 кроків еволюції системи за методологією Spec-Driven Development.

## ⚡ Ключові можливості

1. **Моніторинг 14 топових ліг**: АПЛ, Ла Ліга, Серія А, Бундесліга, Ліга 1, УПЛ, Екстракласа, єврокубки (ЛЧ, ЛЄ, ЛК, Ліга Націй), НБА та підсумкові турніри ATP/WTA.
2. **AI-аналіз матчів (Gemini)**: каскадне перемикання моделей (`3.5-flash-lite` $\rightarrow$ `2.5-flash-lite` $\rightarrow$ `2.5-flash` $\rightarrow$ `3.8-flash`) для оцінки контексту гри та формування рекомендацій.
3. **Paper Bank (10 000 грн)**: автоматичне віртуальне ведення банку, динамічний стейкінг 2–4%, авторозрахунок за фінальними рахунками (`WON`, `LOST`, `VOID`) та щоденний звіт з ROI.
4. **Високоточний гібридний тригер**: виклик воркфлоу секунда в секунду через безкоштовний **Cloudflare Worker** + **Cron-job.org** без затримок у чергах GitHub.
5. **Динамічний планувальник (`scheduler.py`)**: автоматичний розрахунок контрольних точок за 15 хв до початку матчів та через 115 хв для розрахунку ставок.
6. **Watchdog пульсу (`watchdog.py`)**: автоматичний контроль запізнень черг та алерти в Telegram при затримках $> 25$ хв.

## 🛠 Технологічний стек

* **Мова**: Python 3.10+
* **База даних**: PostgreSQL 15+ (Supabase)
* **API котирувань**: The Odds API v4 (із резервним ключем)
* **Штучний інтелект**: Google Gemini API (v1beta)
* **Візуалізація**: Matplotlib (рендеринг у пам'яті без дисків)
* **Канал сповіщень**: Telegram Bot API (HTML-розмітка, чанкінг $\le 3800$ симв.)
* **Оркестрація**: GitHub Actions + Cloudflare Workers
