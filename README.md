# StatMonitor ⚽📈

Інтелектуальна система спортивного моніторингу коефіцієнтів, аналізу прогрузів ліній за допомогою **Google Gemini AI з Google Search Grounding**, автоматичного віртуального трейдингу (**Paper Bank**), спостережливості (**Web Dashboard**) та доставки аналітики й графіків у **Telegram**.

---

## 🗺 Документація та архітектура

* 🏛 **[Візуальна архітектура системи (docs/architecture.md)](docs/architecture.md)** — детальна C4-схема компонентів, модульний пакет `statmonitor/`, потік даних від тригеру до Telegram та Web UI, діаграма бази даних (ERD).
* 📊 **[Діаграма дорожньої карти SDD (docs/roadmap-diagram.md)](docs/roadmap-diagram.md)** — візуальний прогрес виконання завдань по хвилях (Wave 1–9).

## ⚡ Ключові можливості

1. **Моніторинг футбольних, баскетбольних та тенісних ліг**: АПЛ, Ла Ліга, Серія А, Бундесліга, Ліга 1, УПЛ, Екстракласа, єврокубки (ЛЧ, ЛЄ, ЛК, Ліга Націй), НБА та повне тенісне покриття (ATP, WTA, Davis Cup, Australian Open, Roland Garros, Wimbledon, US Open, Finals) із динамічним автовиявленням активних змагань у The Odds API.
2. **AI-аналіз матчів (Gemini + Google Search)**: каскад моделей (`3.5-flash-lite` $\rightarrow$ `2.5-flash-lite` $\rightarrow$ `2.5-flash` $\rightarrow$ `3.8-flash`) із живим пошуком свіжих новин, лазарету, стартових складів, форми та чуток у реальному часі.
3. **Paper Bank (10 000 грн) та стейкінг за критерієм Келлі**: динамічний розрахунок розміру парі за дробовим критерієм Келлі ($0.25 \times \text{Kelly}$, межі 1–5%), авторозрахунок за фінальними рахунками (`WON`, `LOST`, `VOID`) та відображення % банку в активних ставках UI і Telegram.
4. **Конфігураційна матриця ліг (`config/leagues.json`)**: декларативне керування списком ліг, назвами, категоріями, ринками та індивідуальними порогами просідання коефіцієнтів без зміни коду.
5. **Інтерактивний Telegram-бот (`bot_service.py`)**: двосторонній персональний асистент із клавіатурою швидких дій, командами `/status`, `/bank`, `/bets` (з показом % банку за Келлі), `/today`, `/schedule` та позачерговим запуском моніторингу `/run_now` з перевіркою авторизації `TG_CHAT_ID`.
6. **Smart Rate-Limiter & Credit Budgeter (`statmonitor/limiter.py`)**: динамічна класифікація ліг на HOT (< 6 год), WARM (6..24 год) та COLD (> 24 год) з автоматичними режимами економії (NORMAL/ECO/CRITICAL), що зберігає до 80% квоти The Odds API.
7. **Інтерактивний Web Dashboard (Streamlit Cloud)**: повнорозмірний веб-інтерфейс із динамічним графіком капіталу Plotly, картками AI-вердиктів, таблицями ставок (з колонкою `% банку (Келлі)` та київським часом подій), 5-ключовим монітором квот The Odds API (основний + 4 резервних, сумарний пул 2500 запитів) та безпечним RBAC-доступом (режим перегляду для гостей та адмін-режим із тригером та редагуванням коефіцієнтів).
8. **Модульна архітектура пакету (`statmonitor/`)**: розподіл обов'язків на чисті модулі (`pipeline`, `fetcher`, `limiter`, `league_config`, `bot`, `database`, `ai`, `paper_trading`, `chart`, `notifier`, `config`) та лаконічний оркестратор `main.py` зі збереженням 100% зворотної сумісності.
9. **Високоточний гібридний тригер**: виклик воркфлоу секунда в секунду через **Cloudflare Worker** (`statmonitor.symchak.workers.dev`) + **Cron-job.org**, плюс резервний cron у GitHub Actions (`15,45 * * * *`).
10. **Динамічний планувальник (`scheduler.py`)**: автоматичний розрахунок контрольних точок за 15 хв до початку матчів (Closing Line Value), через 115 хв для розрахунку ставок, автофіксація статусу `EXECUTED` та захист від дублікатів.
11. **Watchdog пульсу (`sys_watchdog.py`)**: автоматичний контроль запізнень черг та алерти в Telegram при затримках $> 25$ хв із розумною фільтрацією повторів.
12. **Версіоновані міграції БД (`migrate.py`)**: DDL-схема, журнал `schema_migrations`, B-Tree індекси на `odds_history`, `events`, `paper_bets`, `sports_poll_log` та оптимізована в'юшка `v_odds_alerts` (міграції `001`–`007`).
13. **Точні бенчмарк-коефіцієнти та ручне редагування (Wave 7, Кроки 18–19)**: розрахунок медіани провідних букмекерів (Pinnacle/Betfair/Unibet), пакетний перерахунок `recalc_odds.py`, редагування коефіцієнтів у Streamlit Web Dashboard, Telegram-боті (`/edit_odds <ID> <коеф>`) та CLI.
14. **Дедуплікація активних ставок та захист від спаму (Wave 8, Крок 27)**: пропуск повторного AI-аналізу та Telegram-сповіщень для матчів, по яких у `paper_bets` уже зафіксовано відкрите парі (`PENDING`).
15. **Вичерпний набір тестів (87 unit-тестів)**: тести матриці ліг (`test_league_config.py`), бота (`test_bot.py`), лімітера (`test_rate_limiter.py`), стейкінгу Келлі (`test_kelly.py`), розрахунку маркетів та медіани (`test_eval_picks.py`), цілісності модулів (`test_modules.py`), планувальника, watchdog, міграцій та дашборду (`test_dashboard.py`).

## 🛠 Технологічний стек

* **Мова**: Python 3.10+
* **База даних**: PostgreSQL 15+ (Supabase) + автоматичний раннер міграцій `migrate.py`
* **API котирувань**: The Odds API v4 (5-рівнева ротація ключів: основний + 4 резервних, сумарний пул 2500 запитів)
* **Штучний інтелект**: Google Gemini API (v1beta) з інструментом Google Search Grounding
* **Веб-інтерфейс**: Streamlit Cloud (`dashboard.py` + Plotly)
* **Візуалізація трендів**: Matplotlib (рендеринг у пам'яті без дисків)
* **Канал сповіщень**: Telegram Bot API (HTML-розмітка, чанкінг $\le 3800$ симв.)
* **Оркестрація**: GitHub Actions + Cloudflare Workers
* **Тестування**: `unittest` (87 тест-кейсів, час виконання < 0.6 с)
