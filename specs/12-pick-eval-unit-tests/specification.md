# SPEC-12: Unit Test Suite for Pick Parsing & Score Evaluation

## 1. Контекст та мотивація
Модуль Paper Trading (`statmonitor/paper_trading.py`) та AI (`statmonitor/ai.py`) виконують критичні чисті операції:
1. `format_pick`: Трансформація сирих маркетів The Odds API (`h2h`, `spreads`, `totals`) у зрозумілі людині українські лейбли (`П1 (Team)`, `Ф2 (+1.5)`, `ТБ 2.5`, `Х (Нічия)`).
2. `eval_outcome`: Визначення результату ставки (`WON`, `LOST`, `VOID`) на основі фінального рахунку матчу (футбол, баскетбол, теніс) для маркетів 1X2, фор та тоталів.
3. `extract_short_pick`: Вилучення чистого найменування ставки з вільного тексту або HTML-відповіді Gemini з нормалізацією дужок, видаленням згадок коефіцієнтів та виявленням маркерів "Пропустити".

Помилка в будь-якій із цих трьох функцій веде до спотворення розрахунку банкролу (ROI, PnL), неправильного закриття ставок або зіпсованих сповіщень у Telegram.

## 2. Вимоги до тестування

### 2.1. `format_pick(market, outcome, point, match_name)`
- **Вже відформатовані маркети**: збереження лейблів, що починаються з `П1`, `П2`, `Х`, `Ф1`, `Ф2`, `ТБ`, `ТМ`.
- **Тотали (`totals`)**:
  - `Over` + point -> `ТБ {point}` (наприклад, `ТБ 2.5`, `ТБ 215.5`).
  - `Under` + point -> `ТМ {point}`.
  - Тотал без point -> коректний fallback (`ТБ` / `ТМ`).
- **Фори (`spreads` або наявність `point`)**:
  - Фора домашньої команди (`outcome == h_team`) -> `Ф1 (+/-point)`.
  - Фора гостей (`outcome == a_team`) -> `Ф2 (+/-point)`.
  - Фора нульова (`point = 0`) -> `Ф1 (+0)`.
  - Стороннє найменування -> `Фора {outcome} ({point})`.
- **Основні результати (1X2 / h2h)**:
  - Домашня перемога -> `П1 ({h_team})`.
  - Перемога гостей -> `П2 ({a_team})`.
  - Нічия (`Draw` / `draw`) -> `Х (Нічия)`.

### 2.2. `eval_outcome(pick_lbl, match_name, h_sc, a_sc)`
- **Тотали (Over/Under)**:
  - Більше / менше цілого або дробового значення: перевірка умов `sum > point` (WON), `sum < point` (LOST), `sum == point` (VOID).
  - Підтримка як українських (`ТБ`, `ТМ`), так і англійських (`Over`, `Under`) префіксів.
- **Фори (Spreads / Handicaps)**:
  - Ф1 з плюсовою, мінусовою та нульовою форою: перевірка різниці `h_sc + point - a_sc`.
  - Ф2 з плюсовою, мінусовою та нульовою форою: перевірка різниці `a_sc + point - h_sc`.
  - Цілочисельна фора: повернення `VOID` при нічиїй з урахуванням фори.
- **1X2 / Moneyline**:
  - П1, П2, Х (Нічия).
  - Перевірка за назвою команди у тексті піку.
- **Невідомі/нерозпізнані маркети**: повернення `None` без падіння скрипта.

### 2.3. `extract_short_pick(ai_verdict, fallback)`
- Обробка порожнього тексту / `None` -> повернення `fallback`.
- Парсинг розділу `📌 **Коротка ставка:**` та `🎯 **Рекомендована ставка:**`.
- Очищення HTML-тегів (`<b>`, `<i>`, тощо) та Markdown (`*`, `_`).
- Видалення «хвостів» з коефіцієнтами (`з коефіцієнтом 1.95`, `@ 2.10`).
- Обробка рекомендацій на пропуск (`"Пропустити"`, `"Утриматися"`) -> `⏭ Пропустити матч`.
- Автобалансування круглих дужок.
