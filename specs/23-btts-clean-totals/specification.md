# SPEC-23: Підтримка ринку «Обидві заб'ють» (BTTS) та фільтрація чистих тоталів (Clean Totals)

## 1. Контекст та мета
У спортивному беттингу ринок «Обидві заб'ють» (**Both Teams to Score / BTTS**) у футболі є одним із найпопулярніших та ліквідних ринків, де часто фіксуються стрімкі прогрузи через кадрові втрати в захисті, повернення ключових бомбардирів або погодні умови.
Водночас ринок тоталів (Totals) у деяких букмекерських лініях містить четвертні азіатські спреди (`0.25`, `0.75`, `1.25`, `1.75`, `2.25` тощо), які розділяють суму ставки на дві частини (половинний виграш / повернення), що створює шум в алертах та ускладнює прозорий автоматичний розрахунок.

**Мета SPEC-23**:
1. **Підтримка ринку BTTS (Обидві заб'ють)**:
   - Додати ринок `btts` до конфігурації всіх футбольних ліг (`config/leagues.json` та `statmonitor/league_config.py`).
   - Запитувати `btts` котирування в `statmonitor/fetcher.py` через The Odds API.
   - Форматувати наслідки ставок у `statmonitor/paper_trading.py:format_pick` («Обидві заб'ють: Так» / «Обидві заб'ють: Ні»).
   - Розпізнавати та парсити вибір у `parse_pick_label` (`btts`, `Yes` / `No`).
   - Автоматично розраховувати статус парі в `eval_outcome` за підсумковим рахунком матчу:
     - Якщо $h > 0$ і $a > 0$: `Yes` $\rightarrow$ `WON`, `No` $\rightarrow$ `LOST`;
     - Якщо $h = 0$ або $a = 0$: `Yes` $\rightarrow$ `LOST`, `No` $\rightarrow$ `WON`.
   - Враховувати BTTS при обчисленні медіанного коефіцієнта `get_market_median_odds`.
   - Сегментувати ставки у групу `Обидві заб'ють` в аналітичному модулі `classify_market_group`.
2. **Фільтрація чистих тоталів (Clean Totals Filtering)**:
   - Дозволяти для ринку тоталів (`totals`) виключно стандартні цілі та половинні лінії: `[0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, ...]`.
   - Відсікати азіатські четвертні спреди (`0.25, 0.75, 1.25, 1.75, 2.25, 2.75...`) ще на етапі збереження сирих котирувань у `fetcher.py` та під час перевірки алертів у `pipeline.py`:
     $$\text{round}(|point \times 100|) \pmod{50} = 0$$

## 2. Архітектурні зміни

### 2.1. Конфігурація ліг (`config/leagues.json`, `DEFAULT_LEAGUES_CONFIG`)
Для всіх 12 футбольних ліг (`soccer_epl`, `soccer_spain_la_liga`, `soccer_italy_serie_a`, `soccer_germany_bundesliga`, `soccer_france_ligue_one`, `soccer_ukraine_premier_league`, `soccer_poland_ekstraklasa`, єврокубків та Ліги Націй) список ринків розширено:
```json
"markets": ["h2h", "totals", "spreads", "btts"]
```

### 2.2. Запит та фільтрація котирувань (`statmonitor/fetcher.py`)
- Запит котирувань динамічно враховує налаштування ринків для кожної ліги.
- При зборі котирувань ринку `totals` четвертні лінії відсікаються за правилом:
```python
if mkt_key == "totals" and pt_val is not None:
    if round(abs(float(pt_val) * 100)) % 50 != 0:
        continue
```

### 2.3. Пайплайн алертів (`statmonitor/pipeline.py`)
- Додатковий фільтр для виключення четвертних ліній у тоталах і спредах.

### 2.4. Розрахунок та ведення віртуального банку (`statmonitor/paper_trading.py`)
- `format_pick`: генерація назв «Обидві заб'ють: Так» та «Обидві заб'ють: Ні».
- `parse_pick_label`: розпізнавання `btts`, `Yes` / `No`.
- `eval_outcome`: миттєвий та точний розрахунок за рахунком $h:a$.
- `get_market_median_odds`: підтримка вибірки з `odds_history` для `market_key = 'btts'`.

### 2.5. Аналітика ринків (`statmonitor/analytics.py`)
- `classify_market_group`: визначення ринку `Обидві заб'ють` для розрахунку Win Rate, ROI та кількості ставок у Breakdown на Web Dashboard.
