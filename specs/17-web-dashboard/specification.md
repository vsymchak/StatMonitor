# Специфікація: Веб-дашборд моніторингу та спостережливості (SPEC-17)

## 1. Контекст та мета
Наразі взаємодія із системою StatMonitor відбувається виключно через текстові та графічні повідомлення в Telegram.
Хоча це зручно для оперативних сповіщень про прогрузи, користувач не має єдиного візуального екрана для:
1. Аналізу динаміки капіталу (крива приросту банку, кумулятивний прибуток у часі).
2. Перегляду повної таблиці історії ставок із фільтрами за лігами, коефіцієнтами та статусами.
3. Моніторингу технічного здоров'я (Watchdog пульс, тривалість останніх запусків, статус виконання розкладу).
4. Перегляду кешованих AI-вердиктів матчів від Gemini.

**Мета SPEC-17**: Створити інтерактивний веб-дашборд на **Streamlit** (`dashboard.py`), який підключається до бази даних Supabase та відображає всю ключову бізнес- і технічну аналітику системи в реальному часі. Дашборд може запускатися локально або безкоштовно публікуватися на **Streamlit Community Cloud**.

## 2. Структура та функціональні блоки дашборду

### Блок 1: Ключові метрики (KPI Header Cards)
* **Поточний банк**: початковий (10 000 грн) + накопичений прибуток (`INITIAL_BANKROLL + SUM(profit_uah)`).
* **ROI**: відсоток окупності інвестицій (`Net Profit / Total Stake * 100%`).
* **Вінрейт (Win Rate)**: відсоток виграшних ставок (`WON / (WON + LOST) * 100%`).
* **Стан системи (Watchdog)**: час останнього пінгу з `system_heartbeat` та тривалість виконання.

### Блок 2: Графік приросту банкролу (Bankroll Growth Chart)
* Інтерактивний графік кумулятивного балансу за часом розрахунку ставок.
* Можливість вибору часового діапазону (останній тиждень, місяць, весь час).

### Блок 3: Вкладка "Ставки" (Active & History Bets)
* **Активні ставки (Pending)**: перелік матчів, що тривають або почнуться найближчим часом, розмір ставки та вибір.
* **Історія ставок (Settled)**: кольорове маркування (зелений — `WON`, червоний — `LOST`, сірий — `VOID`), фільтри за турнірами та статусом, розрахунок прибутку.

### Блок 4: Вкладка "AI-аналітика" (Gemini Verdicts)
* Картки останніх проаналізованих матчів з `ai_match_analysis`.
* Рекомендована коротка ставка, суть прогрузу та ігровий контекст.

### Блок 5: Вкладка "Планувальник і здоров'я" (System & Scheduler)
* Таблиця найближчих запланованих точок з `scheduler_plan` (`PRE_MATCH`, `SETTLE`).
* Лог останніх пінгів та затримок із `system_heartbeat`.
* Кнопка швидкого тригеру воркфлоу через наш API/вебхук.

## 3. Критерії приймання (Acceptance Criteria)

- **AC-1**: Файл `dashboard.py` запускається через `streamlit run dashboard.py` без помилок імпорту чи синтаксису.
- **AC-2**: Дашборд коректно відображає дані при наявності `SUPABASE_DB_URL`, а при його відсутності — показує інформативне вікно з демо-режимом або підказкою щодо підключення.
- **AC-3**: Інтерактивні графіки побудовано з використанням чистих бібліотек (`plotly` / `streamlit.line_chart`) у київському часовому поясі (`Europe/Kyiv`).
- **AC-4**: Створено файл `requirements.txt` з усіма необхідними залежностями для розгортання в 1 клік на Streamlit Cloud.
- **AC-5**: Написано автотести `test_dashboard.py` для перевірки обробки даних та розрахунку аналітичних метрик.
