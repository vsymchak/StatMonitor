# SPEC-25: Interactive League Thresholds Management (Admin UI)

## 1. Мета та Контекст
У системі StatMonitor кожна спортивна ліга має власну динаміку коефіцієнтів та ліквідність маркетів. Попередньо конфігурація зберігалася у статичному файлі `config/leagues.json`, що вимагало ручного редагування та комітів у репозиторій для зміни будь-якого параметра чутливості (наприклад, збільшення мінімального просідання для АПЛ з 5% до 6% або відключення певної ліги на паузу).

Дана специфікація впроваджує інтерактивний інтерфейс у кабінеті адміністратора Streamlit Dashboard для перегляду та налаштування порогів чутливості прогрузів (`min_drop_pct`, `min_odds`, `max_odds`, `enabled`, `markets`) з персистентним збереженням у базі даних PostgreSQL (Supabase) та підтримкою двосторонньої синхронізації з `config/leagues.json`.

---

## 2. Ключові Вимоги

1. **Персистентність у базі даних (DB-backed Configuration)**:
   - Створення таблиці `league_thresholds` у базі даних через міграцію `011_league_thresholds.sql`:
     - `sport_key` (TEXT PRIMARY KEY) — унікальний ідентифікатор ліги (наприклад, `soccer_epl`, `basketball_nba`).
     - `title` (TEXT NOT NULL) — локалізована назва (наприклад, «Англія (АПЛ)»).
     - `category` (TEXT NOT NULL DEFAULT 'soccer') — категорія спорту (`soccer`, `basketball`, `tennis`).
     - `enabled` (BOOLEAN NOT NULL DEFAULT TRUE) — статус активності для сканування та алертів.
     - `min_drop_pct` (NUMERIC(5,2) NOT NULL DEFAULT 5.00) — мінімальний відсоток падіння коефіцієнта для створення алерту.
     - `min_odds` (NUMERIC(5,2) NOT NULL DEFAULT 1.40) — мінімальний допустимий коефіцієнт.
     - `max_odds` (NUMERIC(5,2) NOT NULL DEFAULT 4.00) — максимальний допустимий коефіцієнт.
     - `markets` (JSONB NOT NULL) — перелік активних типів ринків (`h2h`, `totals`, `spreads`, `btts`).
     - `updated_at` (TIMESTAMPTZ NOT NULL DEFAULT NOW()) — час останнього оновлення.
   - Автоматичний початковий посів (seeding) з `config/leagues.json`, якщо таблиця порожня.

2. **Інтерактивна вкладка в Streamlit Dashboard (`🎛️ Пороги ліг (Admin)`)**:
   - Доступна виключно в режимі адміністратора (`is_admin == True` або `?key=ALTECsrs1989_`).
   - Смуга аналітичних KPI:
     - Загальна кількість чемпіонатів у системі.
     - Кількість активних у моніторингу (`enabled = True`).
     - Призупинених (на паузі для економії квоти).
     - Середній встановлений поріг просідання (`min_drop_pct`).
   - **Групування чемпіонатів за видами спорту з прапорцями (Smart Rate-Limiter Control)**:
     - ⚽ **Футбол (Soccer)**: АПЛ, Ла Ліга, Серія А, Бундесліга, Ліга 1, УПЛ, Екстракласа, ЛЧ, ЛЄ, ЛК, Ліга Націй.
     - 🏀 **Баскетбол (Basketball)**: NBA.
     - 🎾 **Теніс (Tennis)**: ATP/WTA Tour, Davis Cup, турніри Grand Slam (Australian Open, Roland Garros, Wimbledon, US Open), ATP/WTA Finals.
     - Кнопки масових дій `[✅ Обрати всі]` та `[❌ Зняти всі]` для кожної категорії спорту.
     - Прапорці (checkboxes) для кожного чемпіонату з відображенням порогів та коефіцієнтів.
     - Пряма інтеграція зі **Smart Rate-Limiter**: вимкнені ліги повністю відсікаються на рівні `get_active_sports_map()`, що запобігає спалюванню квоти The Odds API (пул із 5 ключів).
   - **Форма точкового тюнінгу окремої ліги**: вибір турніру, слайдер `min_drop_pct`, числовий ввід `min_odds` / `max_odds`, мультиселект дозволених ринків (`h2h`, `totals`, `spreads`, `btts`).
   - Кнопка повного скидання до дефолтної конфігурації: «🔄 Скинути всі до дефолтних».

3. **Інтеграція в модуль моніторингу та пайплайну**:
   - `statmonitor.league_config.get_league_thresholds` та `load_leagues_config` першочергово звертаються до БД, а за її відсутності використовують локальний `config/leagues.json` (100% сумісність з офлайн-тестами).
   - `statmonitor.pipeline.py` перевіряє не лише `min_odds`/`max_odds`, а й індивідуальний `min_drop_pct` для конкретної ліги.
