# SPEC-19: Можливість редагування коефіцієнта для нерозрахованих ставок

## 1. Мета та контекст
Під час роботи системи моніторингу коефіцієнтів та віртуального трейдингу (Paper Trading) виникають ситуації, коли:
- Первинна лінія букмекера, з якої зафіксовано сигнал, відрізняється від лінії контори користувача (наприклад, Vbet/Favbet vs азійські чи європейські БК).
- Користувач бажає вручну скоригувати коефіцієнт для активної ставки, яка ще перебуває в грі (`status = 'PENDING'`), щоб фінансовий звіт відображав його фактичний реальний парі.

## 2. Функціональні вимоги
1. **Валідація статусу:** Редагування дозволено виключно для ставок у статусі `PENDING`. Для розрахованих ставок (`WON`, `LOST`, `VOID`) операція блокується з інформативним повідомленням про помилку.
2. **Валідація значення коефіцієнта:** Значення має бути валідним числом у допустимому діапазоні (від `1.01` до `100.00`).
3. **Автоматичний перерахунок потенційного виграшу:** При зміні коефіцієнта система одразу повідомляє новий очікуваний профіт: `stake_uah * (new_odds - 1.0)`.
4. **Транзакційна безпека:** Оновлення в базі даних виконується з обов'язковою перевіркою `WHERE id = %s AND status = 'PENDING'` та `conn.commit()`.

## 3. Інтерфейси доступу
- **Web Dashboard (Streamlit):**
  - У вкладці «Ставки та Капітал» біля таблиці активних ставок додано віджет `✏️ Редагувати коефіцієнт ставки (Edit Odds)`.
  - Селектор нерозрахованої ставки з миттєвим відображенням ID, матчу та поточного коефіцієнта.
  - Поле введення нового коефіцієнта та кнопка збереження з миттєвим оновленням таблиці (`st.rerun()`).
- **Telegram Bot:**
  - Команда `/edit_odds <ID> <новий_коеф>` (або аліаси `/edit_bet`, `/set_odds`).
  - Приклад: `/edit_odds 28 1.58`.
  - Команда `/bets` відображає унікальний ID для кожної ставки в грі.
- **CLI / Термінал:**
  - `python main.py --edit-odds <ID> <коеф> [DB_URL]`
  - `python recalc_odds.py --edit-odds <ID> <коеф> [DB_URL]`

## 4. Архітектурні зміни
- `statmonitor/paper_trading.py`: додано функцію `update_pending_bet_odds(cur, conn, bet_id, new_odds)`.
- `statmonitor/bot.py`: інтегровано обробку команди `/edit_odds` та оновлено `/bets` і `/help`.
- `dashboard.py`: впроваджено інтерактивний блок редагування з `st.expander` та селектором.
- `main.py` / `recalc_odds.py`: додано CLI-аргументи `--edit-odds`.
