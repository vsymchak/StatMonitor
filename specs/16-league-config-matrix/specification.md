# SPEC-16: Multi-Sport & Custom League Configuration Matrix

## 1. Контекст та мотивація
Наразі перелік цільових ліг (`TARGET_SPORTS`), їхні назви (`SPORTS_MAP`) та фільтри коефіцієнтів ($1.40 - 4.00$, просідання $\ge 5\%$) жорстко зашиті в Python-коді (`statmonitor/config.py` та `statmonitor/pipeline.py`).
Це створює незручності:
1. Щоб тимчасово вимкнути лігу (наприклад, міжсезоння або пауза на збірні) або додати новий турнір, доводиться змінювати код і робити git commit/push.
2. Різні види спорту мають різну специфіку просідання: для баскетболу (NBA) рух коефіцієнта на $4\%$ може бути більш значущим, ніж $5\%$ у футболі.
3. Користувач повинен мати можливість налаштовувати список відстежуваних ліг, ринків (`h2h`, `totals`, `spreads`) та порогів через єдиний конфігураційний файл `config/leagues.json`.

## 2. Вимоги до конфігураційної матриці

### 2.1. Формат файлу `config/leagues.json`
Файл містить перелік конфігурацій ліг із полями:
- `key` (string, обов'язкове): ключ виду спорту в The Odds API (наприклад, `soccer_epl`, `basketball_nba`).
- `title` (string, обов'язкове): локалізована назва українською мовою.
- `category` (string): категорія спорту (`football`, `basketball`, `tennis`).
- `enabled` (boolean, за замовчуванням `true`): прапорець активності. Якщо `false` — ліга ігнорується планувальником та опитуванням.
- `min_drop_pct` (float, за замовчуванням 5.0): мінімальний поріг падіння котирування (%) для генерації сигналу.
- `min_odds` (float, за замовчуванням 1.40): мінімальний коефіцієнт.
- `max_odds` (float, за замовчуванням 4.00): максимальний коефіцієнт.
- `markets` (list of strings): перелік ринків для опитування (за замовчуванням `["h2h", "totals", "spreads"]`).

### 2.2. Захист та відмовостійкість (Resilience)
- Якщо файл `config/leagues.json` відсутній або пошкоджений (JSON syntax error), система автоматично перемикається на вбудований дефолтний конфіг без аварійного завершення.
- Змінна середовища `LEAGUES_CONFIG_PATH` дозволяє вказати кастомний шлях до файлу конфігурації.
- 100% зворотна сумісність: змінні `SPORTS_MAP` та `TARGET_SPORTS` у `statmonitor.config` автоматично генеруються з завантаженої матриці.

### 2.3. Модуль `statmonitor/league_config.py`
- `load_leagues_config(path=None)`: завантажує та валідує конфігурацію.
- `get_active_sports_map(config)`: повертає словник `{key: title}` для активних ліг (`enabled=True`).
- `get_active_target_sports(config)`: повертає список ключів для активних ліг.
- `get_league_thresholds(sport_key, config)`: повертає `(min_drop_pct, min_odds, max_odds)` для конкретної ліги.
