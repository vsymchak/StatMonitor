# SPEC-15: Telegram Interactive Bot Commands

## 1. Контекст та мотивація
Досі Telegram використовувався суто в односторонньому режимі (`statmonitor.notifier` надсилав сповіщення про прогрузи, AI-аналіз та щоденні звіти).
Користувачу потрібен швидкий двосторонній доступ через Telegram-чат для:
1. Перегляду поточного статусу системи (`/status` — стан сервісу, Watchdog, останні перевірки).
2. Контролю фінансів (`/bank` — баланс 10 000 грн, ROI, профіт, заблоковані кошти).
3. Перегляду відкритих ставок у грі (`/bets` — список PENDING ставок).
4. Перегляду сьогоднішніх результатів (`/today` — розраховані ставки та денний PnL).
5. Перегляду найближчих контрольних точок розкладу (`/schedule`).
6. Негайного запуску моніторингу в 1 клік прямо з месенджера (`/run_now`).

## 2. Функціональні вимоги

### 2.1. Авторизація та безпека
- Бот є персональним асистентом.
- Якщо задана змінна оточення `TG_CHAT_ID`, бот відповідає на команди тільки повідомленням від цього `chat_id`.
- Запити від сторонніх користувачів відхиляються з повідомленням `⛔ Доступ обмежено.`

### 2.2. Команди бота
1. `/start`, `/help`:
   - Привітання та повний перелік команд із коротким описом.
2. `/status`:
   - Останній зафіксований пульс системи (`system_heartbeat`): статус, час останнього пінгу (за Києвом), тривалість виконання.
   - Стан Smart Rate-Limiter: кількість ліг за категоріями (`HOT`, `WARM`, `COLD`) з `sports_poll_log`.
   - Заплановані контрольні точки на сьогодні.
3. `/bank`:
   - Поточний баланс банку (`INITIAL_BANKROLL + net_profit`).
   - Вільні кошти (`available = current - locked_in_pending`).
   - Заблоковано у відкритих ставках (`locked_in_pending`).
   - Чистий профіт / збиток у грн.
   - Оборот (Turnover) та ROI (%).
   - Вінрейт (Win Rate %).
   - Загальна статистика: всього ставок, виграно, програно, повернення, в грі.
4. `/bets`:
   - Список усіх активних ставок (`status='PENDING'`) з бази `paper_bets`.
   - По кожній ставці: назва матчу, турнір, маркет (`pick_label`), коефіцієнт, розмір ставки (грн), час початку (Київ).
5. `/today`:
   - Список ставок, розрахованих сьогодні (`settled_at >= сьогодні 00:00 за Києвом`).
   - Символи результату: 🟢 WON, 🔴 LOST, ⚪ VOID.
   - Підсумковий денний прибуток/збиток.
6. `/schedule`:
   - Найближчі 5 контрольних точок моніторингу з `scheduler_plan` (`PLANNED`).
7. `/run_now`:
   - Запуск негайного сканування через Cloudflare Webhook / `trigger_dispatch.py`.
   - Повідомлення користувачу про статус старту воркфлоу.

### 2.3. Режими роботи
1. **Long-polling сервіс (`python bot_service.py`)**: безперервний фоновий процес, що обробляє оновлення через `getUpdates`.
2. **Одноразовий виклик (`python bot_service.py --once`)**: обробляє всі накопичені повідомлення з черги та завершує роботу.
3. **Модульна обробка (`statmonitor.bot`)**: чисті функції `handle_command` та `process_telegram_update`, які можна підключати до будь-якого webhook-шлюзу.
