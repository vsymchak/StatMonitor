## 🟩 Wave 3: Вдосконалення планувальника (Scheduler Evolution)

### 8. Dynamic schedule generator based on match kickoff times
* **Розмір**: M
* **Статус**: 🟩 Shipped
* **Опис**: Модуль `scheduler.py` аналізує розклад найближчих матчів у базі (`events.commence_time`) та активні ставки (`paper_bets`) і формує кластеризовані тригери:
  - `PRE_MATCH`: за 15 хвилин до старту блоку матчів для фіксації фінальних прогрузів.
  - `SETTLE`: через 115 хвилин після старту для розрахунку результату.
  - Зберігає план у `scheduler_plan` та надсилає розклад у Telegram.
* **Залежності**: потрібен крок 2, потрібен крок 7

### 9. GitHub Actions cron healthcheck & missed-run watchdog
* **Розмір**: S
* **Статус**: 🟩 Shipped
* **Опис**: Модуль `watchdog.py` фіксує пульс у таблиці `system_heartbeat` (час, тривалість, метадані), виявляє простій планувальника $> 150$ хв та прострочені контрольні точки з `scheduler_plan` ($> 25$ хв), формує тривожне сповіщення в Telegram та підтримує зовнішній HTTP пінг (`HEALTHCHECK_URL`).
* **Залежності**: потрібен крок 3, потрібен крок 8

### 10. Smart rate-limiter & API credit budget allocator
* **Розмір**: S
* **Статус**: 🟩 Shipped
* **Опис**: Контролер балансу запитів до The Odds API (`statmonitor/limiter.py` + `sports_poll_log`). Динамічно класифікує ліги за терміновістю (`HOT` < 6 год, `WARM` 6..24 год, `COLD` > 24 год) та бюджетними режимами (`NORMAL`, `ECO`, `CRITICAL`), знижуючи витрату квоти на 60–80%.
* **Залежності**: потрібен крок 1, потрібен крок 8

### 11. Hybrid runner support (External webhook / Cloud backup)
* **Розмір**: M
* **Статус**: 🟩 Shipped
* **Опис**: Реалізовано модуль `trigger_dispatch.py` (CLI + API для негайного запуску `workflow_dispatch`), безсерверний шлюз `deploy/cloudflare_webhook.js` для безкоштовного хостингу на Cloudflare Workers та підтримку вхідного параметра `trigger_source` у GitHub Actions воркфлоу.
* **Залежності**: потрібен крок 9

## 🟪 Wave 8: Розумний беттинг та нові маркети (Smart Betting & New Markets)

### 20. Closing Line Value (CLV) Tracking & Beat the Line %
* **Розмір**: M
* **Статус**: 🟩 Shipped
* **Опис**: Фіксація коефіцієнта закриття лінії (Closing Line) у точці `PRE_MATCH` (за 15–25 хв до початку гри або на момент старту) за провідними бенчмарк-букмекерами (Pinnacle/Betfair). Автоматичний розрахунок показника Beat the Closing Line % для кожної ставки у Paper Bank та агрегованої метрики математичного очікування (+EV). Відображення в Web Dashboard (окрема колонка та блок у Breakdown) і в Telegram-боті (/bank).
* **Залежності**: потрібен крок 8, потрібен крок 18

### 21. AI Confidence Score & Value Filtering
* **Розмір**: S
* **Статус**: 🟪 Idea
* **Опис**: Оцінка сили сигналу прогрузу нейромережею Gemini за шкалою 1–10 (Confidence Score) та класифікація ризику (Low / Medium / High). Впровадження автоматичного фільтра: відкриття парі у Paper Bank лише для матчів з оцінкою $\ge 7/10$ та наявністю фундаментальних факторів (травми, ротація, інсайди).
* **Залежності**: потрібен крок 5, потрібен крок 6

### 22. Dynamic Staking via Fractional Kelly Criterion
* **Розмір**: S
* **Статус**: 🟩 Shipped
* **Опис**: Перехід від східчастого стейкінгу (2–4%) до дробового критерію Келлі ($0.25 \times \text{Kelly}$). Розрахунок оптимальної частки вільного банку на основі вигоди від просідання коефіцієнта відносно початкової ймовірності та захисних меж $[1\%, 5\%]$. Фіксація `kelly_pct` у базі даних (`paper_bets`) та виведення % банку в таблиці активних ставок на Dashboard та у команді `/bets` Telegram-бота.
* **Залежності**: потрібен крок 6, потрібен крок 14, потрібен крок 18

### 23. Both Teams to Score (BTTS) & Clean Totals Filtering
* **Розмір**: M
* **Статус**: 🟪 Idea
* **Опис**: Підтримка ринку «Обидві заб'ють» (`btts`: Yes / No) у футболі в `statmonitor.fetcher`, конфігурації ліг та правилах розрахунку. Фільтрація ринку тоталів (ТБ/ТМ) виключно до стандартних цілих та половинних ліній (0.5, 1.0, 1.5, 2.0, 2.5 тощо) з відсіканням азіатських четвертних спредів (0.25, 0.75, 1.25, 1.75).

### 29. Cloudflare Worker Cron Trigger & Scheduler Noise Elimination

* **Статус**: 🟩 Shipped
